# Portafolio · Jorge Taipe

Sitio personal en HTML, CSS y JavaScript puro. Sin build ni dependencias.

Sitio publicado: https://jorgefts.github.io

## Correr en local

Abrir `index.html` en el navegador, o con servidor local:

```bash
npx serve
```

## Despliegue

GitHub Pages desde la rama `main`, carpeta raíz. Cada push a `main` vuelve a publicar.
